Frequently asked questions




Is my JSON uploaded?
No. Parsing and formatting happen in your browser. Your data never leaves your device — safe even for API keys and private configs (though you should still avoid pasting real secrets into any website).


What does 'Invalid JSON' mean?
The most common causes are trailing commas, single quotes instead of double quotes, unquoted keys, or comments. The error message usually names the problem.


What's the difference between format and minify?
Format adds line breaks and indentation so humans can read it. Minify removes all whitespace so machines can send it as small as possible.


Can I format JSON with duplicate keys?
Yes — the last value wins, as in standard JSON parsing.


Can I format JSON5 or YAML?
No — this tool handles strict JSON only. JSON5 features like trailing commas, comments and single quotes will be flagged as errors, which is exactly what the validator is for.


Is there a size limit?
No. Paste a whole API response or a multi-megabyte config file — formatting is instant and everything stays in your browser.
