Frequently asked questions

Are my QR codes tracked?

No. The code is generated in your browser and the image is a plain PNG. Nothing is logged, and the QR code itself contains only the text you typed.

What can I put in a QR code?

A URL, plain text, or a Wi-Fi login (format: WIFI:T:WPA;S:network;P:password;;). Long text makes a denser code that is harder to scan — keep it short.

Why is my QR code so dense?

Long URLs make dense codes. Use a short link, or lower the error correction level, for a cleaner code.

Can I use the QR code commercially?

Yes — the image is yours, free for any use, no attribution needed.

How big should I print a QR code?

At least 2 × 2 cm (about 0.8 in) for a code scanned from a normal reading distance. For posters scanned from metres away, print it larger — the 1024 px download is made for that.

Does the QR code expire?

No. The code is just your text drawn as squares — there is no server, no link shortener and nothing to expire. It works forever.
